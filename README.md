# Wa593

¿Tú puedes crear una aplicación, por ejemplo, para hacer una tienda donde puedan subir imágenes de productos? Como hacer una tienda virtual, pero ir agregando al carrito con los diferentes atributos que puedan tener. Cada producto ir personalizando, por ejemplo, talla, colores, algunos tamaños, dimensiones, cosas como esas. Todo lo que implica el "e-commerce". Puede ir agregando al carrito y cuando llegue a este punto de comprar, previamente. Bueno, aquí está a punto de comprar, se genera un texto de todo el pedido para mandar por un mensaje a WhatsApp. Se puede hacer. Lo que quiero hacer es un modelo de suscripción en el cual cualquier persona que venga por WhatsApp pueda crear estas tiendas. Y pueda generar su propia tienda para hacer lo que te dije. Que vas a hacer su propia tienda, subir productos, cosas como esas, subir las características, atributos, o sea, que se pueda leer todo, pero al momento de comprar, que se genere como un pedido. ¿Se puede? Y mandar por mensaje a WhatsApp.
